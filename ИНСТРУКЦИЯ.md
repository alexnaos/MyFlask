## 🚀 Как использовать

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск сервера разработки
```bash
python run.py
```
Или:
```bash
python api/index.py
```

Сайт будет доступен по адресу: **http://127.0.0.1:5000**

### Настройка конфигурации
Отредактируйте файл `api/config.ini`:
- Укажите свои данные (имя, email, соцсети)
- Настройте путь к Obsidian vault (если используется)
- Настройте вкладки резюме в секции `[resumes]`

### Добавление контента
1. **Блог**: Добавьте файлы в `api/content/blogs/` в формате Markdown с front matter
2. **Проекты**: Добавьте файлы в `api/content/projects/` в формате Markdown с front matter
3. **Резюме**: Отредактируйте `api/static/resume.md`

## 📁 Текущая структура проекта
```
MyFlask/
├── api/                    # Основное приложение
│   ├── config.ini         # Конфигурация сайта
│   ├── index.py           # Flask-приложение
│   ├── content/           # Контент (блог и проекты)
│   ├── static/            # Статические файлы (резюме, изображения)
│   └── templates/         # HTML-шаблоны
├── requirements.txt        # Зависимости Python
├── run.py                 # Скрипт запуска сервера
├── README.md              # Документация
└── .gitignore             # Игнорируемые файлы
```

## 🔧 Требования
- Python 3.11+
- Установленные зависимости из `requirements.txt`

Проект готов к использованию как локальное Flask-приложение для разработки и демонстрации портфолио.
