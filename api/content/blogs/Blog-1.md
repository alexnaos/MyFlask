## Шпаргалка по уценке

В этой шпаргалке по Markdown представлен краткий обзор всех элементов синтаксиса Markdown.Он не может охватить все крайние случаи, поэтому, если вам нужна дополнительная информация о любом из этих элементов, обратитесь к справочным руководствам по [базовому синтаксису](https://www.markdownguide.org/basic-syntax) и [расширенному синтаксису](https://www.markdownguide.org/extended-syntax).

Это элементы, изложенные в оригинальном проектном документе Джона Грубера.Все приложения Markdown поддерживают эти элементы.

### Разрывы строк

Чтобы создать разрыв строки или новую строку ( < br > ), завершите строку двумя или более пробелами, а затем введите return.
